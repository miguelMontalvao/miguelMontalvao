## 🚀 Projetos em destaque

### 🏆 LandLytics — Global Solution FIAP 2026

Projeto de análise do impacto térmico de data centers utilizando imagens de satélite, sensoriamento remoto e análise de dados geoespaciais.

- Análise de temperatura da superfície terrestre (LST).
- Utilização de imagens Landsat e Google Earth Engine.
- Aplicação de índices ambientais e análise estatística.
- **1º lugar na Global Solution 2026.**

[Repositório](https://github.com/Joao-Thees/Global-Solution)

### ⚽ Pelé Next Gen

Plataforma desenvolvida para conectar jovens atletas, olheiros e clubes, facilitando processos de inscrição, avaliação e descoberta de talentos.

Minha contribuição incluiu otimizações de performance e melhorias de acessibilidade, com auditorias utilizando axe-core e diretrizes WCAG 2.1 AA.

[Repositório](https://github.com/Provadelli/PeleNextGen) · [Minha contribuição](https://github.com/Provadelli/PeleNextGen/pull/6)

### 🌱 Viela Tech

Solução tecnológica voltada ao mapeamento de áreas de risco de tuberculose na Rocinha, integrando monitoramento ambiental, análise de dados e recursos digitais de acompanhamento.

- Desenvolvimento de interface web.
- Integração com sensores e ESP32.
- Utilização de Supabase e ThingSpeak.
- Exploração de dados ambientais e indicadores de vulnerabilidade.

[Aplicação](https://viela-tech.vercel.app/) · [Repositório](https://github.com/miguelMontalvao/Viela-Tech)
